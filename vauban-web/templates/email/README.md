# Email templates (Issue #10)

This directory hosts the plain-text bodies for every notification VAUBAN
sends. The subject line is generated by the matching renderer in
`vauban-web/src/services/mailer.rs`; only the body lives here, so the
contributor experience for "edit this email's wording" is one file per
event.

## Catalogue (P0 + P1)

| Event kind                              | Recipients              | File                                       |
|-----------------------------------------|-------------------------|--------------------------------------------|
| `access_request.submitted`              | approvers               | `access_request_submitted.txt`             |
| `access_request.approved`               | requester               | `access_request_approved.txt`              |
| `access_request.rejected`               | requester               | `access_request_rejected.txt`              |
| `access_request.expired`                | requester + approvers   | `access_request_expired.txt`               |
| `user.created`                          | new user                | `user_created.txt`                         |
| `user.password_reset_requested`         | user                    | `user_password_reset_requested.txt`        |
| `user.locked_after_failed_attempts`     | user + admins           | `user_locked.txt`                          |
| `user.mfa_reset_by_admin`               | user                    | `user_mfa_reset.txt`                       |
| `security.mono_admin_detected`          | superusers              | `security_mono_admin.txt`                  |

## Conventions

* Plain text only (UTF-8). Lines should wrap at ~78 chars.
* Variables are interpolated by the renderer in
  `services/mailer.rs::render_*` -- the templates here are documentary
  fallbacks. The renderer is the source of truth for the wire bytes.
* Anti-CRLF: NEVER put `\r` or `\n` characters in the subject (DB
  CHECK + Mailer guard reject them).
* Branding header `--- Vauban PAM ---` is added by the renderer, not
  by individual templates.
