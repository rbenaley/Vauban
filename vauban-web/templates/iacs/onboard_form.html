Step 1 — Generate the SSH key pair on your EWS

Run the matching command in a terminal on your workstation. The generated key pair stays on your EWS; only the id_VAUBAN.pub file is uploaded below. 

ssh-keygen -t ed25519 -C "VAUBAN" -N "" -f ~/.ssh/id_VAUBAN

Your public key file lives at $HOME/.ssh/id_VAUBAN.pub (e.g. /home/john/.ssh/id_VAUBAN.pub). 

ssh-keygen -t ed25519 -C "VAUBAN" -N '""' -f "$env:USERPROFILE\.ssh\id_VAUBAN"

Your public key file lives at %USERPROFILE%\.ssh\id_VAUBAN.pub (e.g. C:\Users\john\.ssh\id_VAUBAN.pub).
