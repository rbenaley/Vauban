What does this command do?

-L {{ local_forward_port }}:{{ target_host }}:{{ target_port }} — bind 127.0.0.1:{{ local_forward_port }} on your EWS and forward every byte through the bastion to {{ target_host }}:{{ target_port }} (the asset).

{{ session_uuid }}@{{ bastion_hostname }} — the SSH username is the one-shot session UUID issued by VAUBAN.

-p {{ bastion_port }} — the IACS sshd port (separate from the regular VAUBAN proxy).

-N — do not request a shell; only the port forward is allowed.
